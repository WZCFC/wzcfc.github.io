# 心理学与教育学参考

仅在两个体验解释需要区分时选用相关视角。研究结论来自各自的实验任务。游戏里的解释仍需由该局面的界面、行为、自述和结算互证。

| 要区分的情况 | 快拆时怎么查 | 原始研究 |
|---|---|---|
| **信息尚未出现，或出现时玩家正专注于别处** | 先定位线索第一次可见的时点，核对当时玩家在忙什么。操作或事后复述可提示他是否留意，单凭画面位置判断不了。选择性注意实验显示，专注于一项视觉任务的人可能漏掉意外事件。 | [Simons 与 Chabris，1999](https://www.chabris.com/Simons1999.pdf) |
| **看到单条线索，或能把几条线索拼起来** | 还原玩家比较两个选项所需的最少信息。检查这些信息是否必须跨界面、跨时点回忆，以及新手有没有理解所需的背景。分散材料实验说明，必须结合理解的几处材料会带来额外的整合负担。 | [Chandler 与 Sweller，1991](https://doi.org/10.1207/s1532690xci0804_2) |
| **知道发生了结果，或知道为什么发生** | 先还原玩家能看到的结果，再看他能否区分可能原因。若有相似局面，查看他能否说明关键差异并用到下一次。对照案例研究中，在特定课堂任务里先比较再听解释，帮助学习者把理解用到新题。 | [Schwartz 与 Bransford，1998](https://aaalab.stanford.edu/papers/time_for_telling.pdf) |

**例：** 河边只交代「交药开近路」，战斗才出现与交付有关的同伴招式。先把第一次选择时的「药和路」与事后的「物资和战术」分别写清。若反馈仅显示生命上涨，仍要找它是否说清物资如何改变候选、当前条件如何让这次招式成立。能复述招式效果与下次能据此选择，也要分别观察。
