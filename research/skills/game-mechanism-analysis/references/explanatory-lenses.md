# 解释角度与证据

先写一条可能的解释，再选能提出替代解释或帮助查证的角度。学科概念给出查证方向，规则、回放、玩家自述、版本记录与有效对照为具体游戏结论提供证据。

| 角度 | 在什么情况下用 | 要找的区分证据 |
|---|---|---|
| **设计学** | 一项安排似乎改变了玩家可以做什么，或改变了理解动作与结果的方式。 | 把真实可行的动作、决策前看得见的意符、操作到后果的映射、之后收到的反馈分开核对。保留同一规则调整提示，可以看出问题是否出在信息而非选项价值。 [Norman，示能与意符](https://jnd.org/affordances-and-design/) |
| **传播学** | 玩家突然开始关心一个目标，或者同一消息被不同的人理解成不同含义。 | 查消息从谁来、何时到、玩家怎样复述和采信。保持内容与时机，比较来源。用德弗勒的视角对照发出的意思与收到的意思。遇到玩家故事或群体传播，再查是谁讲给谁、哪些内容被带进了下一次游玩。 [Hovland 与 Weiss，来源可信度](https://academic.oup.com/poq/article-abstract/15/4/635/1923117) |
| **心理学** | 线索出现了，玩家却没表现出理解或使用。 | 区分线索缺失、注意被其他任务占用、看见却没拼成预期、理解后主动放弃。先看线索出现时玩家在做什么，再用自述或适当对照查原因。 [Simons 与 Chabris，选择性注意](https://www.chabris.com/Simons1999.pdf) |
| **社会学** | 相同的代价，在陌生人、固定队友或担任不同角色的人之间意义不同。 | 查双方实际权限、共同经历、角色义务及代价分配。若规则与收益相同，比较关系是否改变玩家自己说出的权衡。互惠或信任属于待核解释。 [Gouldner，互惠规范](https://www.jstor.org/stable/2092623) |
| **哲学** | 分析混淆了「同时发生」和「造成变化」，或想判断玩家是否掌握了决策。 | 问哪项条件拿掉后体验仍可能发生，以及在选择当时，玩家能否合理预期某类后果并影响它。反事实用于产生可检验的区别。 |

## 议程设置

当新目标出现、旧目标退居次要，或玩家开始主动留意原本忽略的东西时，用这个角度问：**什么被推到了玩家面前，什么又让他真的有理由去管？**

- **游戏强调了什么？** 查目标、提示、角色话语或玩家故事从哪里来，什么时间出现，是否进了玩家的短期计划。
- **规则让什么变得值得管？** 查需求、成本、风险与结算有没有真的变。消息越显眼和事情越值得做是两种解释，可能同时成立。
- **玩家接下了吗？** 看他能否说出为什么在意这件事，以及它有没有进入权衡。选择没变时仍可能纳入了新的考虑。既定门槛迫使玩家行动时，继续区分完成要求与主动将它当作目标。

要分辨强调和利害变化，可以固定规则只比较消息时机，也可以固定消息只比较真实收益或代价。若玩家能复述却没有把它放进计划，按需要继续查他原本想从玩法得到什么。大众传播研究提供问题的重要性这一分析切口，玩家行为与游戏结算提供本案例的证据。 [McCombs 与 Shaw，议程设置](https://academic.oup.com/poq/article/36/2/176/1853310)

## 使用与满足

当规则基本相同、玩家却开始追求另一种体验，或两个人做出同样的动作但理由不同，用这三问：

1. 玩家在行动前期待得到什么？区分任务要求和他接受任务的理由。
2. 他为什么选择这段玩法去获得它？比较可替代的活动、路线或做法。
3. 实际得到什么？用自述、结算和后续主动选择互证。一次重复行为可能来自偏好，也可能来自任务尚未完成。

应用到游戏内阶段变化时，先把它当竞争解释。体验变化可能来自规则变了、玩家追求变了，或两者相互作用。若能固定情境比较不同目标，或固定目标比较设计安排，优先查能分辨两者的那一组。 [Katz 等，使用与满足](https://academic.oup.com/poq/article-abstract/37/4/509/1816598) · [Palmgreen 等，期待与实际获得](https://journals.sagepub.com/doi/10.1177/009365028000700202)

多人局面可再查谁负责观察、转达和修正计划。若差异来自上一次经历，核对玩家是否把反馈用到了下一次判断。只在这些因素与当前差异有关时展开。
